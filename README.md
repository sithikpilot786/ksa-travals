# KSA TRAVALS - Premium Travel Company Website

A modern, luxurious informational website for KSA TRAVALS, built with React.js, Tailwind CSS, Framer Motion, and Lucide React Icons.

## Features

✨ **Premium Design**
- Glassmorphism effects
- Dark Blue, Gold, and White color scheme
- Smooth animations and transitions
- Mobile-first responsive design

📱 **Sections**
- Hero Section with floating animations
- Company About Section
- Leadership Profiles (Founder & CTO)
- Team Showcase with Carousel
- Professional Services Cards
- Popular Destinations Gallery
- Why Choose Us Trust Section
- Client Testimonials Slider
- Photo Gallery with Lightbox
- Contact Section with Form

🎯 **Features**

- **React.js 18** - UI Library

## Installation

### Prerequisites
- Node.js 16+ 
- npm or yarn

### Setup

1. **Install Dependencies**
```bash
npm install
```

2. **Start Development Server**
```bash
npm run dev
```
The website will open at `http://localhost:3000`

3. **Build for Production**
```bash
npm run build
```

4. **Preview Production Build**
```bash
npm run preview
```
